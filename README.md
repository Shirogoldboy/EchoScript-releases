# EchoScript

App de transcrição de áudio/vídeo em texto — pra estudar (aulas, vídeos) e
organizar sessões de RPG. Roda 100% local (Whisper), com opção de identificar
quem está falando e transcrever links do YouTube.

## Download

Baixe a versão mais recente na aba [Releases](../../releases) — pegue o
`EchoScript-v1.zip`, extraia e dê dois cliques em `EchoScript.exe` dentro da
pasta extraída. Não precisa instalar Python, ffmpeg nem nada — já vem tudo
junto.

Leia o `LEIA-ME.txt` incluído na pasta pra instruções de uso.

O código-fonte deste projeto é privado.
